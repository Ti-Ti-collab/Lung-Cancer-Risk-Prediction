# Lung Cancer Risk Prediction

This machine learning project predicts the risk of lung cancer based on health-related data. It was developed as part of my Health Analytics program to explore predictive modeling in healthcare.

## 📌 Problem Statement

Lung cancer is one of the leading causes of death globally. Early detection through data analysis can save lives. The goal of this project is to predict the likelihood of lung cancer using patient data.

## 🧠 Machine Learning Workflow

- Data Cleaning & Preprocessing  
- Exploratory Data Analysis (EDA)  
- Feature Selection  
- Model Building (Logistic Regression, Random Forest, XGBoost)  
- Model Evaluation (Accuracy, F1 Score, ROC-AUC, Confusion Matrix)  
- Model Deployment  

## 🛠️ Technologies Used

- Python  
- Pandas, NumPy  
- Scikit-learn  
- Matplotlib, Seaborn  
- Jupyter Notebook  
- Streamlit  
- Visual Studio Code  

## 🗂️ Project Structure

This project is divided into the following components:

- **Performance Metrics:** A documentation of the three metrics used to assess the quality and reliability of the machine learning models.  
- **EDA & Visualization:** A thorough descriptive analysis and visual exploration of the cleaned dataset, offering insights into variable relationships and patterns.  
- **Model Building & Evaluation:** Logistic Regression, Random Forest, and XGBoost models were trained and evaluated using confusion matrices and ROC-AUC curves.  
- **Web Application:** A Streamlit web app was created to demonstrate real-time prediction using the trained model.  
- **Presentation Slides:** A professional PowerPoint presentation was prepared to communicate key results, insights, and visuals from the project.
