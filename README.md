# Lung Cancer Risk Prediction
My machine learning project to predict the risk of lung cancer based on health-related data. It was built as part of my Health Analytics program to explore predictive modeling in healthcare.

## Problem Statement
Lung cancer is a leading cause of death worldwide. Early detection through data analysis can save lives. The goal of this project is to predict the likelihood of lung cancer using patient data.

## Machine Learning Workflow
- Data Cleaning & Preprocessing
- Exploratory Data Analysis (EDA)
- Feature Selection
- Model Building (Logistic Regression, Random Forest, XGBoost)
- Model Evaluation (Accuracy, F1 Score, ROC-AUC, Confusion Matrix)
- Deployment

## Technologies Used
- Python
- Pandas, NumPy
- Scikit-learn
- Matplotlib, Seaborn
- Jupyter Notebook
- Streamlit
- VSC
    
## Project Structure
This project structure is broken into the following parts:
- Expected objectives and performance metrics; This file documents the three performance metrics that could be use to assess the quality and reliabilty of my machine learning models.
- Exploratory Data Analysis and Visualization; I conducted a thorough descriptive analysis and visualization of my cleaned dataset to gain insights into the relationships amongst various variables which were further interfpreted.
- Model Building and Evaluation; I used three Logistic Regression, Random Forest, XGBoost to train on the training data to develop the machine learning models, predicted the target in the test data and further generated the Confusion Matrix and AUC-ROC curves for the target prediction.
- Web Application; I deployed trained model as a web app on streamlit to showcase prediction.
- PowerPoint Presentation; I created professional powerpoint slides that communicates the key results/output/graphs for this project.
